# HN Later Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the full HN Later MVP as an Android-first Expo app.

**Architecture:** Expo Router owns navigation, React Query owns Hacker News cache, and storage modules own local Read Later and settings state. Pure logic is isolated from React screens so it can be tested with Jest.

**Tech Stack:** Expo SDK 57, React Native 0.86, TypeScript, Expo Router, React Query, MMKV, FlashList, Reanimated, Jest Expo.

## Global Constraints

- Android MVP only.
- Dark mode only, default dark.
- Official Hacker News Firebase API only.
- No backend, no account, no EAS build.
- GitHub Actions must build a debug APK and upload it as an artifact.
